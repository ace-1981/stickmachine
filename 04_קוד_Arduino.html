שלב 4: קוד Arduino

מכונת הדבקת מדבקות לכרטיסי אשראי — תוכנה

איך הקוד עובד?
💡 הנקודה המרכזית — סנכרון
בזמן ההדבקה (LABELING), מנוע M2 (הובלה) ומנוע M3 (מדבקה) חייבים לרוץ באותה מהירות ליניארית (מ"מ/שנייה).
אם M2 מהיר יותר — המדבקה תימרח. אם M3 מהיר יותר — המדבקה תתקמט.

הקוד מוודא ששתי המהירויות זהות: 250 מ"מ/שנייה.
מבנה הקובץ
חלקשורותתיאור
הגדרות פינים~40-65כל הפינים של החיישנים, מנועים, LED
קבועים מכניים~67-95צעדים, קטרים, מידות כרטיס
מרחקים (כיול)~97-108⭐ ערכים שצריך לכוון — feedDistance, labelTriggerOffset
מהירויות (כיול)~110-120⭐ מהירויות ניתנות לשינוי
מכונת מצבים~122-2206 מצבים + ERROR + TEST
תפריט בדיקה~222-350בדיקת מנועים, חיישנים, כיול
פונקציות עזר~352-420המרות, LED, timeout
🔧 איך להעלות את הקוד לארדואינו
1
התקנת Arduino IDE
הורידו מ: https://www.arduino.cc/en/software
גרסה 2.x מומלצת
2
התקנת ספריית AccelStepper
בתוך Arduino IDE:
• לכו ל: Sketch → Include Library → Manage Libraries
• חפשו: AccelStepper
• לחצו Install
3
פתיחת הקוד
• File → Open
• נווטו לתיקייה: מכונת מדבקות\sticker_machine\
• פתחו: sticker_machine.ino
4
בחירת לוח
• Tools → Board → Arduino Mega or Mega 2560
• Tools → Port → COM? (המספר שמופיע כשמחברים USB)
5
העלאה
• לחצו על ← (חץ ימינה) — כפתור Upload
• חכו ל: "Done uploading"
• פתחו: Tools → Serial Monitor (115200 baud)
⚠️ חשוב!
• אל תחברו מנועים לפני ההעלאה הראשונה — קודם בדקו שהקוד עולה בלי שגיאות
• בדיקה ראשונה: פתחו Serial Monitor ושלחו 'T' (תפריט בדיקה)
• בדקו חיישנים: שלחו '4' — וודאו שהחיישנים מגיבים נכון
⚡ חיבור USB לתכנות
מכונת מצבים — הסבר מפורט
1
IDLE — ממתין לכרטיס
המכונה בודקת את חיישן S1 (פידר). כשכרטיס מזוהה → עוברת ל-FEEDING.
LED מהבהב לאט (1 שנייה)
2
FEEDING — דחיפת כרטיס
מנוע M1 מסובב את גלגל הגומי, שדוחף את הכרטיס התחתון מהמחסנית אל המסילה.
מרחק: 55 מ"מ (ניתן לכיול)
כשהמנוע מסיים → עוברת ל-TRANSPORT
3
TRANSPORT — הובלה לאזור הדבקה
מנוע M2 מוביל את הכרטיס לאורך המסילה. ממתין שחיישן S2 יזהה את הכרטיס.
מהירות: 250 מ"מ/שנייה
כש-S2 מופעל → עוברת ל-LABEL_OFFSET
4
LABEL_OFFSET — מיקום מדויק
הכרטיס ממשיך לנוע, אבל המדבקה עוד לא מתחילה.
הקוד מחשב את המרחק המדויק מנקודת S2 עד למיקום שבו המדבקה צריכה להתחיל.
מרחק: 30 מ"מ (ניתן לכיול! זה הערך הכי חשוב)
כשהמיקום מושג → עוברת ל-LABELING
5
★ LABELING — הדבקה!
מנוע M3 מתחיל למשוך את רצועת המדבקות דרך ה-Peel Plate.
M2 ו-M3 חייבים לרוץ באותה מהירות!
המדבקה מתקלפת מהרצועה ונדבקת על הכרטיס בלחץ הרולר.
אורך מדבקה: 28 מ"מ (+ 5% מרווח)
כש-S3 מופעל או שהמנועים סיימו → עוברת ל-EXIT
6
EXIT — סיום
הכרטיס נדחף ליציאה. מונה מחזורים עולה ב-1.
השהייה של 200ms → חוזרת ל-IDLE
🔴 ERROR — שגיאה
מופעל אוטומטית ב-3 מצבים:
• Timeout: מצב נמשך יותר מ-8 שניות
• S2 לא הגיב: הכרטיס לא הגיע לאזור ההדבקה
• חריגה: משהו שגוי בלוגיקה

איך לצאת: שלח 'R' ב-Serial Monitor (אפס מכונה)
תזמון מחזור — 1.5 שניות
⭐ כיול — הערכים שצריך לכוון
⚠️ הערכים בקוד הם נקודת התחלה!
כל מכונה שונה קצת. אחרי ההרכבה, תצטרך לכוון 2-3 ערכים.
אפשר לכוון דרך תפריט הבדיקה (Serial Monitor) בלי לשנות קוד!
ערךברירת מחדלמה זהאיך לכוון
feedDistance 55.0 מ"מ כמה מ"מ הפידר דוחף את הכרטיס אם הכרטיס לא מגיע למסילה — הגדל. אם יוצא יותר מדי — הקטן.
labelTriggerOffset ⭐ 30.0 מ"מ מרחק מ-S2 עד תחילת ההדבקה זה הערך הכי חשוב!
אם המדבקה קדימה מדי — הגדל.
אם המדבקה אחורה מדי — הקטן.
כוון ב-'6' (+1מ"מ) ו-'7' (-1מ"מ) בתפריט בדיקה.
transportSpeedMM 250.0 מ"מ/ש מהירות הובלת הכרטיס אם כרטיסים מחליקים — האט. כוון ב-'8'/'9' בתפריט.
✅ תהליך כיול מומלץ
1. בדוק חיישנים: שלח '4' — וודא שכל 3 החיישנים מגיבים
2. בדוק מנועים: שלח '1', '2', '3' — וודא שכל מנוע מסתובב
3. הרץ מחזור עם כרטיס: שלח '5' (Single Cycle) — צפה במכונה
4. כוון offset: בדוק איפה המדבקה נופלת על הכרטיס. שלח '6' או '7' להזזה
5. חזור: הרץ עוד מחזור ובדוק. חזור עד שהמדבקה במרכז הכרטיס.
חישוב VREF — כוונון זרם דרייבר
// TMC2209 VREF calculation // ======================================= // Motor rated current: 1.5A (typical NEMA17) // TMC2209 R_sense: 0.11Ω (board default) // // Formula: VREF = I_RMS × √2 × R_sense × 5 // = 1.5 × 1.414 × 0.11 × 5 // = 1.166V // // Start at 70%: VREF ≈ 0.8V // Increase slowly if motors skip steps // =======================================
💡 איך לכוון VREF
1. מדד עם מולטימטר בין GND לנקודת VREF (בורג קטן על הדרייבר)
2. התחל ב-0.5V (בטוח)
3. הפעל מנוע. אם מדלג צעדים — הגבר ב-0.1V
4. אם הדרייבר מתחמם מאוד — הנמך!
📡 תפריט Serial Monitor
פתיחת Serial Monitor

הגדרות: 115200 baud — צד ימין למטה

🔍 פתרון בעיות נפוצות
בעיהסיבה אפשריתפתרון
מנוע לא זז EN pin ב-HIGH, חיווט שגוי, VREF נמוך מדי בדוק חיווט. בתפריט בדיקה שלח '1'/'2'/'3'. הגבר VREF.
מנוע רוטט אבל לא מסתובב חוטי סליל מוחלפים מדוד התנגדות בין כל 2 חוטים. שני חוטים עם ~3Ω = סליל אחד.
מנוע מדלג צעדים VREF נמוך / מהירות גבוהה מדי הגבר VREF ב-0.1V. הנמך מהירות בפקודה '9'.
חיישן לא מגיב חיווט שגוי, VCC/GND מוחלפים שלח '4' בתפריט. בדוק 5V ו-GND. בדוק עם מולטימטר.
חיישן תמיד BLOCKED משהו חוסם את חריץ החיישן נקה את החיישן. בדוק שאין לכלוך.
מדבקה לא במרכז labelTriggerOffset לא מכוול כוון ב-'6' (+1מ"מ) או '7' (-1מ"מ). הרץ מחזור ובדוק.
מדבקה מתקמטת M3 מהיר מ-M2 ודא שהמהירויות זהות. בדוק קוטר רולר.
מדבקה נמרחת M2 מהיר מ-M3 ודא שהמהירויות זהות. בדוק קוטר רולר.
כרטיס נתקע מסילה צרה, מהירות גבוהה הרחב מסילה. הנמך מהירות.
TIMEOUT error כרטיס לא הגיע לחיישן בזמן בדוק חיישנים. הנמך מהירות. הוצא כרטיסים תקועים.
דרייבר מתחמם VREF גבוה מדי הנמך VREF. הוסף גוף קירור (heatsink).
🔴 לעולם לא:
• אל תנתק חוט מנוע כשהמתח דלוק — ישרוף את הדרייבר
• אל תחליף חוטי מנוע כשהמנוע פועל
• אל תגע במנוע בזמן סיבוב
• אל תכניס יד למכונה בזמן פעולה
✅ סדר בדיקה ראשונה
1. חבר רק Arduino + USB (בלי מנועים, בלי 24V)
2. העלה קוד. פתח Serial Monitor. ודא שרואים הודעת "Ready"
3. שלח 'T' — ודא שתפריט מופיע
4. כבה. חבר חיישנים + 5V (עדיין בלי 24V ובלי מנועים)
5. הדלק. שלח '4' — בדוק חיישנים
6. כבה. חבר דרייברים + מנועים + 24V
7. הדלק. שלח '1', '2', '3' — בדוק מנועים אחד אחד
8. שלח '5' — הרץ מחזור מלא עם כרטיס
9. כוון labelTriggerOffset עד שהמדבקה במרכז
